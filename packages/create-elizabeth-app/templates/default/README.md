# Elizabeth App

This is a reactive web application built with [Elizabeth](https://github.com/elizabeth-js/elizabeth).

## Getting Started

Start the development server:

```bash
bun run dev
```

Open `http://localhost:3712` in your browser.

## Editing

* **Pages**: Add or edit `.liz` files in `src/pages/`.
* **API Routes**: Add `.ts` files in `src/api/` and export `GET`, `POST`, etc.
* **Components**: Add reusable UI elements in `src/components/`.

## Building for Production

Build your app for production:

```bash
bun run build
```

Then start the production server:

```bash
bun run start
```
