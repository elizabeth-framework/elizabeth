# Security Policy

## Supported Versions

Elizabeth is currently in early development. Security fixes are provided for the latest published version only.

| Version | Supported |
| ------- | --------- |
| latest  | ✅ |
| older versions | ❌ |

## Reporting a Vulnerability

If you discover a security vulnerability in Elizabeth, please report it privately by email:

**elizabethjs.2026@gmail.com**

Please include:

- A clear description of the issue
- Steps to reproduce, if possible
- The affected package or feature
- Any relevant logs, screenshots, or proof of concept

Please do not open a public GitHub issue for security vulnerabilities until we have had time to investigate.

We will try to review reports as soon as possible and follow up with next steps.
